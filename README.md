## Site Description:
This project is focused on data visualization with stocks. We hope to plot the data and use stock chart patterns (https://www.investopedia.com/articles/technical/112601.asp) to extrapolate information about where a stock will move. Since we are limited to previous data, we can instead use a certain time period (ie. a year) and verify our predictions with data from the next few months. We also hope to make this project more interactive than just visualizing data by allowing users to follow stocks, follow others' stock portfolios, and create their own stock patterns. While the first two are rather straight forward, the last is intended for a stock guessing game where users will be able to guess which stock will have the highest yield in the next month.

## Install Guide:
### Prerequisites:
Must have Git and Python installed beforehand.
1. Git: https://git-scm.com/book/en/v2/Getting-Started-Installing-Git
2. Python: https://www.python.org/downloads/
3. Using Git: https://novillo-cs.github.io/apcsa/tools/

### Procedure:
1. Locate green <>Code button on main page of project repository
2. Copy the HTTPS URL
3. Open the terminal on your local machine and navigate to the desired directory
4. Clone the repository in the corresponding directory:
```
git clone https://github.com/esokul007/JEWZ__jacobl143_ethans175_yinweiz_ziyadh2.git
```
5. Setup a virtual environment
```
python3 -m venv <name>
```
6. Activate virtual environment
```
. <name>/bin/activate
```
7. cd into the repo, ```
cd PATH/TO/JEWZ__jacobl143_ethans175_yinweiz_ziyadh2```

8. Install required packages
```
pip install -r requirements.txt
```
